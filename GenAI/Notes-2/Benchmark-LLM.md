Core Benchmarks
- MMLU (Massive Multitask Language Understanding).
- Tests: broad knowledge across 57 subjects (STEM, humanities, social sciences, etc.).
- Format: multiple-choice questions.
- Goal: measure general reasoning and factual recall.
  
- GSM8K (Grade School Math 8K).
  Tests: arithmetic and word problem solving at grade-school level.
  Format: math word problems requiring step-by-step reasoning.
  Goal: evaluate mathematical reasoning and chain-of-thought.
  
- HumanEval
  Tests: code generation and correctness.
  Format: Python programming problems with unit tests.
  Goal: measure functional coding ability of LLMs.
  
- SWE-bench
  Tests: software engineering tasks in real-world GitHub repos.
  Format: bug fixing, feature implementation, PR validation.
  Goal: benchmark practical coding + repo comprehension.

🧠 Advanced Reasoning Benchmarks

- GPQA (Graduate-Level Physics QA)
  
  Tests: physics reasoning at graduate level
  Format: multiple-choice and open-ended questions
  Goal: push LLMs beyond high-school math into advanced scientific reasoning.
  
- MMMU (Massive Multi-discipline Multimodal Understanding)
  
  Tests: multimodal reasoning across text + images
  Format: questions requiring diagrams, charts, or visual context
  Goal: benchmark vision-language models in diverse academic disciplines.

⚙️ Functional & Applied Benchmarks

- BFCL (Benchmark for Function Calling in LLMs)
- Tests: structured tool use and API/function calling accuracy
- Format: tasks requiring correct JSON/function call outputs
- Goal: measure reliability of LLMs in tool-augmented workflows.
