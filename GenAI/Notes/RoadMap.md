
 **Quarter 1: Foundations of AI & Machine Learning**
**1. Mathematics for AI**
   - Linear Algebra: Vectors, matrices, eigenvalues, singular value decomposition
   - Probability & Statistics: Bayes theorem, distributions, hypothesis testing
   - Calculus: Derivatives, gradients, optimization techniques (e.g., gradient descent)

**2. Python for AI**
   - Transitioning from .NET to Python (NumPy, Pandas, Matplotlib)
   - Object-oriented programming in Python
   - Writing efficient AI workflows with Python

**3. Machine Learning Basics**
   - Supervised vs. Unsupervised Learning
   - Regression (Linear, Logistic)
   - Classification (Decision Trees, Random Forests, SVM)
   - Clustering (K-Means, DBSCAN)
   - Model evaluation (Confusion Matrix, Precision-Recall, ROC Curve)

**4. Deep Learning Fundamentals**
   - Neural Networks: Perceptron, Multi-layer Perceptron (MLP)
   - Activation Functions (ReLU, Sigmoid, Softmax)
   - Backpropagation & Optimization (SGD, Adam)
   - Introduction to TensorFlow & PyTorch

 **Quarter 2: Advanced AI & Neural Networks**
**5. Computer Vision**
   - Convolutional Neural Networks (CNNs)
   - Image classification, object detection (YOLO, Faster R-CNN)
   - Transfer Learning & Pretrained Models (ResNet, VGG, EfficientNet)
   - OpenCV for image processing

**6. Natural Language Processing (NLP)**
   - Tokenization, Embeddings (Word2Vec, GloVe)
   - Transformers & Self-Attention (BERT, GPT)
   - Named Entity Recognition (NER), Sentiment Analysis
   - LangChain for AI-driven applications

**7. Reinforcement Learning**
   - Markov Decision Processes (MDP)
   - Q-Learning, Deep Q-Networks (DQN)
   - Policy Gradient Methods
   - Applications in robotics & gaming

 **Quarter 3: AI Engineering & Deployment**

**10. Vector Databases & Retrieval-Augmented Generation (RAG)**
   - Vector embeddings (FAISS, Annoy)

   - LangChain for dynamic AI applications
