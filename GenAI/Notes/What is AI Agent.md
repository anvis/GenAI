
LLM enable us to provide an Input and extract the output from LLM. but LLM doesn't have access to real time data or data that it is not trained, 
and these LLM cannot perform any task like checking your calender, browsing the internet for some information etc...,

Key Traits of LLM
1) They have limited knowledge of proprietary information like our personal information or internal company data.
2)LLM are passive:-  They wait for our prompt and then they respond.

   
LLM use Control Logic:
It means If I train my LLM to always check my calender then for every prompt I give it will check in the calender,
As in above example, it can pull my events from calender, but If i ask about weather, it cannot answer as it is trained always to check in calender.
we can add multiple control logic's to handle each sceanrio but its tedious.

RAG, is a process that helps AI models to look things before they answer. it a type of AI workflow.
