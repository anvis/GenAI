## Machine Learning categories

Machine learning models can be broadly classified into three categories: 

**Supervised Learning** 

In supervised learning, we have labeled data—meaning we know the correct answers. The model learns by mapping inputs to known outputs.

Supervised algorithms require humans to provide both input and desired output, 

- Linear Regression: Used for predicting continuous values (e.g., stock prices, house prices).
- Logistic Regression: Used for binary classification problems (e.g., spam detection, fraud detection).
- Decision Trees & Random Forests: Used for classification and regression tasks (e.g., customer segmentation, recommendation systems).
- Support Vector Machines (SVM): Great for text classification or image recognition when data is well-separated.
- Neural Networks (ANNs, CNNs, RNNs): Used for complex tasks like image recognition (CNNs) or language translation (RNNs).

**Unsupervised Learning**

In unsupervised learning, there are no labels. The model identifies patterns in the data.

Unsupervised algorithms do not need to be trained with desired outcome data. Instead, they use an iterative approach called deep learning to review data and arrive at conclusions. Unsupervised learning algorithms are used for more complex processing tasks than supervised learning systems.

- Clustering (K-Means, DBSCAN): Used for grouping similar data points (e.g., customer segmentation, anomaly detection).
- Principal Component Analysis (PCA): Used for dimensionality reduction (e.g., reducing dataset complexity while retaining key features).
- Autoencoders: Used for feature learning and anomaly detection (e.g., detecting fraudulent transactions).

**Reinforcement Learning** 

This is used when an agent learns by interacting with an environment and receiving rewards or penalties based on its actions.

- Q-Learning & Deep Q-Networks (DQN): Used in gaming AI, robotics, and autonomous systems.
- Policy Gradient Methods: Used for continuous decision-making applications like self-driving cars.

  Key Components**
- **Agent**: The learner (e.g., a chess-playing AI).
- **Environment**: The system the agent interacts with (e.g., a chessboard).
- **Actions**: The moves the agent can make (e.g., playing a chess piece).
- **Rewards**: Positive or negative feedback (e.g., winning or losing points).
- **Policy**: The agent’s strategy for choosing actions.
