
## **supervised learning**

In supervised learning, a data set consists of inputs and outputs, and the supervised learning algorithm learns how to map examples of inputs to examples of outputs in the best possible way. 

This function is a mathematical function, which is also called a mapping function, and the supervised learning algorithm seeks to find the most suitable function, in other words, supervised learning is called the approximation of a function. 

In supervised learning problems, we assume that there is an unknown function or relationship between the input and output data, and the supervised machine learning algorithm tries to approximate this function. 

Although we assume that such a mapping function exists, we don’t know anything about it, and that’s why we call it an approximation.

The True function (actual function) that maps the inputs to the outputs is unknown and is often referred to as the target (or objective) function, and the goal of the learning process is to use only the available data (the training data) to approximate the target function. 

If we knew the target function, we wouldn’t need to approximate supervised machine learning algorithms.

Examples of supervised learning applications:

Classification Problems (Discrete Outputs)

- Spam Detection – Classifies emails as "spam" or "not spam" based on labeled examples.
- Medical Diagnosis – Predicts diseases (e.g., "diabetic" or "non-diabetic") using patient data.
- Sentiment Analysis – Identifies emotions (e.g., "positive" or "negative") in text reviews.
- Fraud Detection – Flags fraudulent transactions by learning from past fraud cases.
- Face Recognition – Classifies images into known identities (e.g., "Person A" vs. "Person B").
  
Regression Problems (Continuous Outputs)

- Stock Price Prediction – Estimates future stock prices based on historical trends.
- Weather Forecasting – Predicts temperature or rainfall based on past climate data.
- Real Estate Pricing – Determines house prices using features like location and size.
- Sales Forecasting – Estimates future product sales using past purchasing data.
- Energy Consumption Prediction – Forecasts electricity usage based on time patterns.


## **Un supervised learning**

In unsupervised learning, a data set consists only of inputs, without labeled outputs, and the algorithm aims to discover patterns, structures, or relationships within the data.

Since there is no predefined mapping between inputs and outputs, the algorithm does not approximate a known function but instead seeks to identify hidden structures. 

The learning process involves grouping, associating, or reducing the dimensions of the data without explicit supervision.

Unlike supervised learning, which approximates a function that maps inputs to outputs, unsupervised learning focuses on discovering underlying patterns from unlabeled data.

Rather than approximating a function like in supervised learning, unsupervised models analyze data distributions and relationships to reveal insights. 

Examples of Unsupervised Learning Approaches

- Clustering Algorithms – Identify groups within data (e.g., customer segmentation).
- Dimensionality Reduction – Compress data while retaining important features (e.g., Principal Component Analysis).
- Anomaly Detection – Detect unusual patterns or fraud (e.g., credit card fraud detection).
- Association Rule Learning – Find relationships between variables (e.g., product recommendations).
- Self-organizing Maps – Learn topological structures of data (e.g., organizing feature similarities).
