
Generative models learn how data is generated (joint distribution), while discriminative models focus on distinguishing between classes (decision boundaries)

---

Generative Models can generate new data.

Use Cases:
- Image generation (GANs)
- Speech synthesis
- Anomaly detection

A generative model might learn how digits are written and generate new handwritten digits.

Discriminative Models will focus on data classification.

Use Cases:
- Spam detection
- Sentiment analysis
- Fraud classification

A discriminative model learns to separate spam from non-spam emails based on features.
