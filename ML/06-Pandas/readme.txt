A DataFrame in Pandas is essentially a two-dimensional, tabular data structure similar to a spreadsheet or SQL table.
 It's one of the core components in the Pandas library and is widely used for data manipulation and analysis in 
 Python.

Pandas provides two types of classes for handling data:

Series: a one-dimensional labeled array holding data of any type
such as integers, strings, Python objects etc.

DataFrame: a two-dimensional data structure that holds data like a two-dimension array or a table with rows and columns.

Use DataFrame.head() and DataFrame.tail() to view the top and bottom rows of the frame respectively:
