## Linear Transmission

Simply put, a linear transformation is a function between two vector spaces that preserves the operations of vector addition and scalar multiplication. 
These transformations translate abstract mathematical theories into tangible, real-world applications.

A transformation T is considered linear if it satisfies the following two properties for any vectors u and v, and any scalar c:

- Additivity: T(u + v) = T(u) + T(v) (This means that the transformation respects vector addition.)
- Homogeneity: T(c⋅u) = c⋅T(u)        (This property ensures that the transformation scales vectors appropriately. )

Examples of Linear Transmission are Rotation, Reflection, Translation etc..,

- Rotation: Rotating a shape around an axis without changing its size or shape.
- Reflection: Flipping a shape over a line or plane.
- Translation: Moving a shape from one position to another without altering its size or orientation.

Properties: After these transformations, the shape retains:

- Same size
- Same area
- Same angles
- Same line lengths

## Non-Linear Transformations


Non-linear transformations do not preserve the properties of vector addition and scalar multiplication. These transformations can warp, bend, or change the shape of the object.
