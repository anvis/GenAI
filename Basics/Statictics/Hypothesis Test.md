
---

**Hypothesis Testing**:

- A method to test an assumption about a population using sample data.
- Helps determine if there's enough evidence in a sample to infer a condition is true for the entire population.

---

Steps in Hypothesis Testing

1. Formulate a Hypothesis
  Example: “The drug affects blood pressure.”
  This is the alternative hypothesis (what you want to prove).

2. Define the Null Hypothesis
  Opposite of the alternative: “The drug has no effect.”
  Assumed true unless evidence suggests otherwise.

3.Collect Sample Data
  Randomly select individuals from the population.

4. Run the Hypothesis Test
  Use statistical methods to compare sample results against the null hypothesis.

5. Calculate the P-value
  Probability of observing the sample result (or more extreme) if the null hypothesis is true.

6. Decide Based on Statistical Significance
  If P-value < 0.05, reject the null hypothesis (result is statistically significant).
  If P-value ≥ 0.05, do not reject the null (result likely due to chance).

---

Errors in Hypothesis Testing

  Type I Error: Rejecting a true null hypothesis (false positive).
    Believing the drug works when it doesn’t.
  Type II Error: Not rejecting a false null hypothesis (false negative).
    Believing the drug doesn’t work when it actually does.
